## 导入契约

- 21个link、12个转动关节、8个固定关节。`collapse_fixed_joints=False`，保留四足端和四个 `*_calf_collision_link`。
- `replace_cylinder_with_capsule=False`，保持URDF/MuJoCo的圆柱尺寸和平端面一致，不继承base中的自动替换；Go2不变。
- `self_collisions=-1`，保留原JSON的20对命名装配排除，不关闭全机自碰撞。
- 每个URDF collision对应一个形状，不自动VHACD；导入形状数或命名不符时显式报错，不静默禁用碰撞。
- 足端选择 `_foot_link`；非足端选择 `thigh`、`calf`，包含小腿载体，不把小腿接触当足端支撑。
- 总质量 `12.04293025733458 kg`，显式惯量不变；原小腿和固定载体各保留一半质量/惯量、相同质心，复合动力学不变。
- 小腿机械范围 `[-2.7227, -0.8378] rad`，理想关节力矩上限 `23.7 N m`，不收紧限位代替碰撞。
- 顺序FL/FR/RL/RR，每腿hip/thigh/calf，默认 `[0, -0.75, -1.5]`；PD `20 / 0.5`、动作缩放0.25与部署YAML一致。

`PrimuusEnv / PrimuusCfg / PrimuusCfgPPO` 直接继承base，不导入Go2。修改模型须同步两侧URDF、引用网格、JSON及部署XML，不修改Go2资产来接入Primuus。

## 当前检查范围

本地MuJoCo 3.8.1检查默认姿态、1000组角度（200组站姿附近、800组全限位随机）、每腿401个小腿角度、PD站立、倒地、侧倒、关节摆动及固定机身最大力矩折膝。原模型无穿入的785组在新模型未新增穿入；扫描首次负距离角均约 `-2.633167 rad`，最大力矩折膝停止角逐项相同，约 `-2.617338 rad`。

有限动力学检查无数值警告，采样未见新自碰撞穿入；新轨迹在旧169形状包络复查也未记录到穿入。非接触区的最小几何距离最大差异约2.5 mm，不是逐点等价。不能据此保证任意强制姿态、冲击或CAD原始三角面完全无相交。

当前PD保持默认角4 s后机身Z仍约0.234 m，与旧模型一致，低于高度奖励0.25 m容差下限，增益需后续评估。本次只改碰撞资产与Primuus圆柱导入开关，不改奖励、PD、观测、关节限位或接触求解参数。

物理步长0.25 ms，PD每步更新，策略50 Hz，4096环境；接触求解参数不变。

### 增大步长尝试（未采用）

2026-10-16，本地MuJoCo保持同一65形状模型及原控制/接触参数，固定机身、髋和大腿，对四小腿从默认角施加 `-23.7 N m` 折膝，并逐物理步检查瞬时接触。dt=0.25 ms基线未记录到负距离；0.3125 ms、0.4 ms、0.5 ms分别出现约1.38 mm、4.81 mm、1.86 mm的最深穿入，独立凸体半空间求交也确认实际体积交叠。0.5 ms的站立、倒地、侧倒、摆动虽无数值警告，仍不足以批准该设置。

MuJoCo默认refsafe使有效接触时间常数至少为2*dt；增大步长也会使原0.5 ms的接触响应变软。诊断中仅把0.25 ms基线的接触时间常数调成1 ms，同样出现约2.81 mm负距离，该诊断设置没有写入正式模型。末态停止角仍近似一致，不能只看末态或训练是否报错来判定接触稳定。

因此本轮保留 `dt=0.00025 / substeps=1 / decimation=80`，未同步候选参数至服务器，也未启动新训练；没有修改保护开关、几何、限位、PD或接触参数。进一步增大步长需先确认是否联调接触参数，现有10轮GPU训练结果仍只对应0.25 ms基线。本地一次性数据在 `/tmp/primuus-timestep-20261016-cnyaZe/`。
