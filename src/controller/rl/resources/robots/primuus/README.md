# Primuus 仿真资源

本目录仅描述当前 Primuus 的简化关节力矩模型，用于 sim2sim 准备，不模拟齿轮和连杆传动。

## 文件职责

| 文件 / 目录 | 作用 |
| --- | --- |
| `urdf/primuus.urdf` | 机械结构来源：17 个 link、12 个转动关节、4 个固定足端关节及质量惯量 |
| `stl/` | 原始显示网格，保持 CAD 外观不变；机身、髋和足端仍将对应网格用于碰撞 |
| `collision/*_thigh_motor.STL` | 从原始大腿中分离的电机碰撞网格 |
| `collision/*_thigh_plate.STL` | 离线拆分板件的来源，不再直接作为运行时的单个凸包 |
| `collision/convex/` | 保留大腿活动通道的凸分块，以及小腿主杆凸网格；URDF/XML 共用相同 OBJ |
| `collision/self_collision_exclusions.json` | 正常装配接触的 12 对命名几何；供训练侧通用过滤接口使用 |
| `primuus.xml` | MuJoCo 本体：保留 URDF 的关节坐标和完整惯量，增加浮动机身、执行器、虚拟 IMU 和传感器 |
| `scene_flat.xml` | 引用本体并加入地面、灯光和相机；不复制机器人结构 |
| `../../../config/primuus.yaml` | 机器人运行配置：模型和策略路径、关节顺序、PD、默认姿态及观测契约 |

XML 使用相对于本目录的网格路径，不依赖最初的 CAD 导出目录。修改 URDF 的结构、惯量、坐标或碰撞后，必须同步 XML 并复核；两者不会自动同步。

URDF 与 XML 的机身及四条腿统一使用浅银灰色 `RGBA=(0.898039, 0.917647, 0.929412, 1)`，XML 碰撞几何的显示颜色也保持一致。颜色仅影响渲染，不改变碰撞或动力学；原始 STL 不修改，光照与阴影仍会产生明暗差异。

XML 的大腿、小腿 `body.quat` 和 `joint.ref` 成对补偿，使默认加载姿态与 `home` / YAML 的默认角一致，避免全零小腿角超出限位、初始足端穿入地面。外部关节角的含义仍与 URDF 一致，不能只改 `ref` 而不更新对应的 body 姿态。

## 碰撞约定

- 和 Go2 一样分离显示与碰撞几何，但不复制 Go2 的尺寸。大腿的两侧板、通道壁和局部凸台分别建模，避免一个凸包把小腿活动通道填满。孔洞和边缘采用保守近似，不表示逐三角面精确碰撞。
- 小腿碰撞使用主杆网格的凸包，轴心的小螺帽只保留显示；质量、惯量仍包含完整原始组件。正常的转轴装配接触不应阻止关节转动。
- MuJoCo 在本模型内关闭父子过滤，并用 `contype/conaffinity` 仅排除机身与髋安装处、髋与本腿大腿电机安装处。固定足端和本腿小腿属于同一焊接组，不产生内部碰撞。大腿板件与髋、小腿与大腿、足端与大腿及不同腿之间均可产生接触。
- 碰撞位为：通用几何 `1`，机身 `2`，FL/FR/RL/RR 髋 `4/8/16/32`，对应大腿电机 `64/128/256/512`。双方的兼容掩码均拒绝对方才排除，其他组合保持启用。不要把 `filterparent` 改回默认值来消除接触。
- 四条腿小腿的仿真工作范围统一为 `[-2.4, -0.8378] rad`。原始三角面检查显示，约 `-2.6296 rad` 开始发生远离膝轴的大腿/小腿实体干涉；`-2.4` 还留出了数值误差与凸近似的余量。这是当前模型的安全工作范围，不是实测机械硬限位或电机裸轴转角。
- Isaac Gym / PhysX 始终过滤 articulation 的相邻父子 link，自碰撞掩码无法解除。训练侧由上述工作限位阻止小腿进入干涉区；MuJoCo 使用相同限位，并额外保留相邻组件接触。不能只在 MuJoCo 启用碰撞而继续让 URDF 使用旧下限。
- 接触及小腿限位使用 `2 ms` 响应时间，接触裕量为 `1 mm`，物理步长为 `1 ms`。有限步长和软约束仍可能产生微小数值穿入或限位越界；不能承诺任意大力、超大步长或手工拖入非法姿态时绝对零穿透。

原始 STL、质量惯量、关节坐标和默认姿态不变；小腿工作下限已在 URDF/XML 同步更新。模型更新时必须同步凸分块引用、工作限位与过滤规则，不能只替换显示文件。

### 训练侧接入边界

当前训练工程尚未注册 Primuus 任务，本目录修复不代表已有 Primuus 策略或已经完成训练验证。后续接入时将完整目录复制到训练侧资源目录，并使用同一个 URDF；不要仅拷贝 `stl/`。

训练侧 `LeggedRobotCfg.asset` 已支持 `self_collision_exclusions`：读取本目录 JSON 列表，设置 `self_collisions=-1` 保留配置后的过滤位，并保持 `collapse_fixed_joints=False`、一份预分解凸网格对应一个 collision。导入形状数量或名称不一致时会报错，不会静默关闭碰撞。四个足端固定关节也标记为 `dont_collapse`，保留独立足端状态索引。

Isaac Gym 的 `self_collisions` 是数值过滤参数：`0` 开启可用自碰撞（仍过滤相邻 link），正数关闭全部自碰撞，`-1` 使用资产过滤位；不是 `False/True` 意义的启用开关。不要沿用 Go2 当前的 `1` 来接入 Primuus。

### 本次验证范围

- 150 组位姿的机身/关节坐标、质量矩阵和重力/科氏项与修复前一致；原始显示 STL 和 URDF 质量惯量未改。
- MuJoCo 检查无控制倒地、PD 站立、持续 `23.7 N m` 折膝、关节摆动与侧倒，无数值警告。40 组末态及最深折膝角的原始三角面复查未发现膝轴 25 mm 范围以外的大腿/小腿相交。
- 最大力矩工况下，MuJoCo 小腿最低瞬时角约 `-2.4302 rad`，稳态约 `-2.4003 rad`。软限位存在约 `0.03 rad` 瞬时越界，但仍与原始实体干涉边界相差约 `0.20 rad`；不要把工作下限理解为绝对不会越过的数值截断。
- 服务器 Isaac Gym 的 CPU/GPU PhysX 均导入 17 个 body、12 个关节和 161 个碰撞体，并检查了倒地、PD 站立、固定机身最大力矩折膝。CPU/GPU 折膝均被限制在约 `-2.4 rad`，命名过滤的多形状顺序及非法配置检查通过。

以上不是策略行走验收，也不是 4096 环境训练或性能基准。本次不新增 Primuus 训练任务，不在工程中保留一次性验证脚本。

## 当前参数

- 12 个执行器均按关节端力矩解释，控制输入和执行器力矩限制均为 `[-23.7, 23.7] N m`；URDF 的 effort 同步为 23.7。
- 默认姿态按 `FL / FR / RL / RR` 排列，每腿为 `hip=0、thigh=-0.75、calf=-1.5 rad`。
- YAML 的 `kp=60、kd=1.5` 是此前平地站立测试基线，不是电机厂家推荐值，也不代表带载抬腿和行走已通过。
- 物理步长为 `0.001 s`，策略每 20 步更新一次，即 50 Hz；PD 由现有运行器逐物理步更新。
- 地面和碰撞网格摩擦采用当前测试假设 `0.8 0.005 0.0001`。不模拟电机热限制、转速-力矩曲线或额外传动。
- XML 的 `imu` 是放在 `base_link` 原点的虚拟传感器，不代表实机安装位置。

## 查看模型

在工程根目录执行：

```bash
python3 -m mujoco.viewer --mjcf=src/controller/rl/resources/robots/primuus/scene_flat.xml
```

默认加载和 `home` 关键帧均为与 YAML 一致的参考位姿，足端初始距地约 2 mm。查看器不会读取 YAML 或自动运行 PD；直接播放没有控制器的模型仍会倒地，不能用它判断站立控制效果。仅检查静态姿态时按空格暂停，再调整 Joint 面板。

## 策略配置

当前没有 Primuus 专用策略。`config/primuus.yaml` 的 `policy_path` 预留为 `models/primuus/policy.pt`，可以改为真实 Primuus TorchScript / ONNX 文件的路径。不得用 Go2 策略代替。

实际策略到位，并确认默认姿态、PD、动作顺序、45 * 6 观测和缩放参数与训练侧一致后，使用现有入口：

```bash
python3 src/controller/rl/rl_controller/deploy_mujoco_rl.py \
  --config src/controller/rl/config/primuus.yaml
```

策略缺失时配置检查会拒绝启动，这是当前预期行为。本次没有添加无策略 PD 模式，也没有修改 Go2 的默认入口或配置。
