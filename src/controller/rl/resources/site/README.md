# 场地模型

此目录集中存放场地与独立障碍资源。机器人机械定义仍在`../robots/`中维护。

| 文件 | 用途 |
| --- | --- |
| `ROBOCON2027.xml` | 原始完整比赛场景；保留原Go2引用、障碍布局和物理设置，仅调整迁移后的引用与网格路径 |
| `stairs.xml` | 独立台阶几何片段，在MJCF的`worldbody`或静态`body`内include，不包含机器人、地面或全局物理设置 |
| `scene_primuus_stairs.xml` | Primuus台阶审核场景，包含本体、台阶、地面、灯光和视角 |
| `narrow_bridge.xml` / `scene_primuus_narrow_bridge.xml` | 单木桥几何片段 / Primuus单木桥审核场景 |
| `ramp.xml` / `ramp_assets.xml` / `scene_primuus_ramp.xml` | 斜坡及顶部平台几何 / 斜坡网格定义 / Primuus斜坡审核场景 |
| `high_wall.xml` / `scene_primuus_high_wall.xml` | 高墙几何片段 / Primuus高墙审核场景 |
| `limit_frame.xml` / `scene_primuus_limit_frame.xml` | 限高框架几何片段 / Primuus限高框架审核场景 |
| `stepping_stones.xml` / `scene_primuus_stepping_stones.xml` | 梅花桩几何片段 / Primuus梅花桩审核场景 |
| `brick_wood_pit.xml` / `brick_wood_pit_assets.xml` / `scene_primuus_brick_wood_pit.xml` | 砖木坑几何 / 填充底层网格 / Primuus砖木坑审核场景 |
| `generate_brick_wood_pit.py` | 按固定尺寸生成砖木坑资源与场景 |
| `tire_array.xml` / `tire_array_assets.xml` / `scene_primuus_tire_array.xml` | 轮胎阵几何 / 凸扇段网格 / Primuus轮胎阵审核场景 |
| `obstacles.xml` / `obstacles_assets.xml` | 通用低障碍、台阶、斜坡及矮块；由`../robots/primuus/scene_obstacles.xml`加载 |

完整场景用于保留场地来源，当前Primuus开发和审核使用独立场景。其余障碍尚未逐项审核，不能将整场文件视为全部满足规则的已核定模型。

## obstacles综合场景

`../robots/primuus/scene_obstacles.xml`加载Primuus本体和本目录的`obstacles.xml`、`obstacles_assets.xml`。
这是后续复杂地形训练配套的通用障碍场景，尺寸不表示比赛规则要求。
机器人初始位置为原点，面向+X；障碍前方保留平地。

| 通道 | 位置与尺寸 |
| --- | --- |
| 主通道，中心y=0 | x=1.3m、2.0m处分别为4cm、8cm高横条，沿X厚0.20m、宽1.60m |
| 主通道台阶 | x∈[3.0,5.1]m，4cm一级，上至12cm平台后下行；踏面深0.30m，顶平台长0.90m，宽1.60m |
| 坡道，中心y=2.5m | x∈[1.5,4.5]m，两端各1m长坡道、中间1m平台；平台高0.20m、宽1.60m，坡度0.2，约11.3° |
| 矮块，中心y约−2.5m | x=1.5～4.1m范围内四块2/4/6/8cm高盒体，长宽0.5～0.6m |

`obstacles.xml`的`pos`是中心坐标，box的`size`是半尺寸；斜坡网格和接触默认值在`obstacles_assets.xml`。
各障碍为静态实体，接触参数沿用Primuus平地场景；不增加隐形踏板或护栏。
可整体移动或旋转包含几何的父body，修改后重新加载场景生效。

在部署工程根目录运行：

```bash
python3 src/controller/rl/rl_controller/deploy_mujoco_rl.py \
  --config src/controller/rl/config/primuus.yaml \
  --xml-path src/controller/rl/resources/robots/primuus/scene_obstacles.xml
```

训练工程通过`train_primuus.py --task primuus_obstacles`选择障碍任务，实际使用Isaac Gym生成的随机凸块/凹陷、正反台阶和正反坡网格。
MuJoCo为固定通道布局，与训练任务覆盖相近类型，不是训练地形拼图的逐点复刻。
默认`primuus.yaml`仍选择平地；障碍策略的模型路径通过`--policy-path`或YAML的`policy_path`指定。

## 台阶尺寸与坐标

来源为`ROBOCON2027.xml`的`stairs_07_00`、`stairs_07_01`、`platform_08`。
尺寸依据《2027年足式机器人挑战赛-V1.0》第3.1节、PDF第5页的“沟壑组合”。
提取范围为台阶侧的两级短踏面及顶部平台，不包括沟壑、另一侧平台和斜坡。

局部原点位于第一阶前缘中心的地面投影；+X为上阶方向，+Y为横向，+Z向上，单位为米。

| 几何名称 | X范围 | Y范围 | 顶面高度 | 踏面深度 |
| --- | --- | --- | --- | --- |
| `stairs_step_1` | 0～0.32 | -0.40～0.40 | 0.12 | 0.32 |
| `stairs_step_2` | 0.32～0.64 | -0.40～0.40 | 0.24 | 0.32 |
| `stairs_top_platform` | 0.64～1.44 | -0.40～0.40 | 0.36 | 0.80 |

共三次0.12m高度提升，总长1.44m、宽0.80m，顶部平台0.80m×0.80m。
MuJoCo的box `size`为半尺寸；三个箱体均从地面向上填实，接缝没有间隙。
按规则使用绿色外观；摩擦参数`0.8 0.1 0.1`沿用来源场景，属于仿真假设，并非比赛材料的实测值。

复用时可以整体平移或绕Z旋转父body，不应分别改变各踏面的相对位置：

```xml
<body name="stairs" pos="1 0 0">
  <include file="stairs.xml" />
</body>
```

审核场景将第一阶前缘放在世界坐标x=1m，顶部平台后缘为x=2.44m。
机器人位于原点并朝+X，使用本体默认姿态和`home`关键帧。地面为水平平面，场地无额外护栏。
独立模型可用于上台阶及反向下台阶检查；平台后缘是0.36m高的竖直边界，并非下行楼梯。
场景沿用Primuus本体的物理设置，不继承整场文件的RK4设置。

## 单木桥、斜坡与高墙

三个独立场景均以+X为行进方向，障碍前缘位于世界x=1m，机器人初始位置和朝向沿用Primuus本体。
地面、PD、机械模型和策略契约与台阶场景一致。几何片段的局部原点均在障碍入口中心的地面投影。
摩擦统一沿用原场地`0.8 0.1 0.1`，外观按规则以绿色为主，参数不代表实测材料属性。

| 障碍 | 来源几何 | 局部尺寸及范围 | 独立场景的世界X范围 |
| --- | --- | --- | --- |
| 单木桥 | `platform_04` | 长3m、宽0.4m、高0.1m；x∈[0,3]，y∈[-0.2,0.2] | [1,4] |
| 斜坡 | `ramp_10_mesh`、`ramp_10`、`platform_09` | 坡度20°、宽0.8m、升高0.36m；水平长度约0.989092m；高端连接0.8m×0.8m平台 | [1,约2.789092] |
| 高墙 | `high_wall_00` | 沿行进方向厚0.08m、横向宽0.8m、高0.3m；x∈[0,0.08]，y∈[-0.4,0.4] | [1,1.08] |

依据《2027年足式机器人挑战赛-V1.0》第3.1节、PDF第5～6页。
单木桥保留实体长方体，两端为0.1m高的台沿，没有额外引坡或护栏。
斜坡使用封闭实心三棱柱，底面位于地面，高端与平台无缝相接；水平长度由`0.36/tan(20°)`计算，
将原网格0.989m的取整长度修正为约0.989092m。完整场地文件保留原值。
黄色平台对应规则中的启动区2；该独立模型未绘制启动区红色虚线，也不包含沟壑和台阶侧。
平台后缘为0.36m竖直边界，不是第二段斜坡；下坡应从平台沿-X返回。
高墙保留固定箱体碰撞，未增加引坡；规则提到顶部包钢，但未单独模拟其材料差异或假设钢板厚度。

单木桥、高墙与台阶一样，在静态父body内include几何片段。斜坡另需在主MJCF顶层引用其网格资源：

```xml
<mujoco>
  <include file="ramp_assets.xml" />
  <worldbody>
    <body name="ramp" pos="1 0 0">
      <include file="ramp.xml" />
    </body>
  </worldbody>
</mujoco>
```

网格顶点内嵌于`ramp_assets.xml`，不依赖机器人mesh目录；父body负责整体平移和旋转。

## 限高框架

尺寸以《2027年足式机器人挑战赛-V1.0》第3.1节、PDF第5页为准：净高290mm、净宽800mm、长800mm，颜色为绿色。
长度按通行方向的整体外长建模。原场地的`limit_frame_pillar_*`和`limit_frame_beam_*`只作为结构参考；
原模型外长880mm，独立模型修正为规则规定的800mm，完整场地源文件不随独立模型改写。
规则未标注杆件截面；本模型暂用40mm×40mm方杆作为建模假设，不能将其视作规则尺寸。

| 项目 | 局部范围 / 数值 |
| --- | --- |
| 行进方向及整体长度 | +X，x∈[0,0.80]m |
| 通道净宽 | y∈[-0.40,0.40]m，宽0.80m |
| 最低横梁底面 | z=0.29m，地面z=0 |
| 整体外宽 / 外高 | 0.88m / 0.33m，由40mm方杆假设推导 |
| 前后立柱中心 | x=0.02、0.78m |
| 左右立柱中心 | y=+0.42、-0.42m |
| 前后横梁之间的内部距离 | 0.72m；此数值不是规则所指的整体长度 |

结构包含四根立柱和顶部前、后、左、右四根横梁，顶部中央开放；没有顶板、侧墙或地面门槛。
框架为静态碰撞体，在父body内引用`limit_frame.xml`即可，不依赖网格文件。
审核场景将前缘放在世界x=1m、后缘x=1.8m，Primuus从原点朝+X接近入口。
摩擦参数沿用原场地的`0.8 0.1 0.1`，属于仿真假设，规则没有提供摩擦系数。

规则第4.3节允许机器人以任意姿态从框架下穿过，允许触碰，但禁止暴力撞击（例如造成框架移位）。
本模型不模拟框架被推移，不能仅以静态框架未移动认定符合比赛要求；后续需结合接触与完整穿越判断。

## 梅花桩

平面布局以规则书第3.1节、PDF第6页的文字和俯视尺寸图为准，独立模型总长3.5m；桩体与两侧平台按当前高度要求均为0.1m。
原XML的`stepping_stones_01_*`及`platform_02/03`只作结构参考；原模型同排方块中心距0.3m，
不符合规则中的0.4m净距，独立模型按下表重排，完整场地源文件保留原值。

局部原点为入口平台前缘中心地面投影，+X为通行方向，全部顶面高0.1m。

| 部分 | 局部位置与尺寸 |
| --- | --- |
| 入口平台 | x∈[0,0.8]m，y∈[-0.4,0.4]m，高0.1m，整体0.8m×0.8m×0.1m |
| 出口平台 | x∈[2.7,3.5]m，y∈[-0.4,0.4]m，高0.1m，整体0.8m×0.8m×0.1m |
| 左排三个方块 | 中心x=1.0、1.6、2.2m，y=+0.2m；各0.2m×0.2m×0.1m |
| 右排三个方块 | 中心x=1.3、1.9、2.5m，y=-0.2m；各0.2m×0.2m×0.1m |

入口平台到两排首块的净距分别为0.1m、0.4m；出口侧反向对应。
同排中心距0.6m、净距0.4m；两排中心距0.4m、横向净距0.2m。
布局关于(1.75,0)中心对称，六块分别命名，供后续记录每块的足端接触。
所有几何为绿色实心箱体，间隔中没有隐藏踏板；摩擦沿用场地假设值`0.8 0.1 0.1`。
审核场景整体平移到x=1m，出口平台后缘为世界x=4.5m。

## 轮胎阵

以规则书第3.1节、PDF第5页的165/70R13外胎及2×4排列为准。
单胎名义外径约0.55m、内径约0.33m、胎面宽度0.165m；平放时将轴向宽度作为模型整体高度。
四胎一侧为长边，两胎一侧为短边，按图相邻中心距0.55m，总占地2.2m×1.1m。
原场地轮胎外径0.56m、中心距0.56m且高度约0.105m，独立模型按规则重建，不沿用这些尺寸。

局部入口短边前缘为x=0，+X经过四列；各列轮胎中心x=0.275、0.825、1.375、1.925m，
两排中心y=±0.275m，轮胎中心z=0.0825m，底面最低点z=0、最高点z=0.165m。
审核场景整体平移到x=1m，阵列后缘为世界x=3.2m。

规则未给出外胎断面曲线、橡胶弹性、质量、花纹及受力变形参数，本模型采用固定刚性椭圆截面环作为近似：
环中心线半径R=0.22m，径向半轴a=0.055m，竖向半轴b=0.0825m。
参数化表面为`((R+a*cos(phi))*cos(theta), (R+a*cos(phi))*sin(theta), b*sin(phi))`，再整体抬高0.0825m。
不将该截面当作真实165/70R13外胎的完整机械模型，也不模拟轮胎整体滚动、平移或软胎形变；足端仍可在接触面滑动，接触摩擦为未辨识假设值。

为保留碰撞孔洞，每个轮胎由48个凸扇段组成，每段的两端截面各16个点；八胎共384个碰撞geom。
所有扇段复用`tire_array_assets.xml`内的单段网格，通过旋转拼环，显示与碰撞使用相同分段几何。
不能将整环换成单个凸碰撞mesh，否则中心孔会被凸包填实。
曲面离散为多面体：名义内径0.33m，对边切面处的最小孔径约0.329293m；外径最大0.55m，
中间角度略向内收缩。这是网格近似误差，不是额外设定的轮胎尺寸。
胎面与地面接触处、相邻轮胎接近处采用曲面接触，不补平轮胎间空隙或中心孔。

复用时在主MJCF顶层include `tire_array_assets.xml`，在静态父body内include `tire_array.xml`，
方式与斜坡的资源/几何拆分一致。每胎有独立body名`tire_left_1`至`tire_right_4`，便于区分接触。

## 砖木坑

外形依据规则书第3.1节、PDF第5页：L形，外侧两条长边各2m，两端短边各1m，绿色护栏高0.15m。
局部原点为入口短边中心的地面投影，先沿+X进入，再转向+Y离开。
外轮廓顶点依次为`(0,-0.5),(2,-0.5),(2,1.5),(1,1.5),(1,0.5),(0,0.5)`，单位为米。
入口为x=0、y∈[-0.5,0.5]，出口为y=1.5、x∈[1,2]。
审核场景父body位于`(1,0,0)`，世界范围为x∈[1,3]、y∈[-0.5,1.5]。

坑底与外部地面齐平，填充最高处为z=0.10m，比护栏顶面低0.05m；100mm填充深度是用户指定值，规则未规定填充深度。
六段外围护栏包含入口和出口短边，机器人需跨过边缘；护栏厚25mm是建模假设，外轮廓尺寸包含护栏。
按规则示意图用对角线`x+y=1.5`区分碎砖区和树皮区；入口侧为碎砖，出口侧为腐松树皮。
对角线仅为材料分界，不增加规则未明确要求的凸起隔板。

| 填料 | 表面方块边长 | 实体底层高度 | 方块顶面高度 |
| --- | --- | --- | --- |
| 碎砖 | 30、40、50mm；规则未规定，属于建模假设 | 50mm | 80～100mm |
| 树皮 | 10、14、18、20mm；位于规则10～20mm范围内 | 80mm | 90～100mm |

按用户要求，表面填料均用小正方体近似，采用固定排列和交错尺寸；碎砖360块、树皮2751块。
表面方块下方使用两个凸实心底层填充，保留方块之间的凹槽，不逐层生成不可见颗粒。
所有填料和护栏均为固定刚体，不模拟碎砖移动、树皮压缩或颗粒重排；摩擦`0.8 0.1 0.1`沿用原场地假设值，未按材料辨识。
该近似用于几何接触和落脚训练准备，不能代表真实松散填料的全部动力学。

复用时在主MJCF顶层include `brick_wood_pit_assets.xml`，在静态父body内include `brick_wood_pit.xml`。
网格顶点内嵌于资源文件，方块使用MJCF `replicate`展开为具名静态geom，需要支持该元素的MuJoCo版本。
可从工程根目录重新生成，尺寸和排列参数在生成器内维护；场景外观模板来自同目录的`scene_primuus_high_wall.xml`：

```bash
python3 -B src/controller/rl/resources/site/generate_brick_wood_pit.py
```

## 查看与加载策略

在`quadruped`工程根目录查看几何：

```bash
python3 -m mujoco.viewer \
  --mjcf=src/controller/rl/resources/site/scene_primuus_stairs.xml
```

裸Viewer不运行PD或策略，播放后的自由下落不能作为策略表现判断。加载现有Primuus策略：

```bash
python3 src/controller/rl/rl_controller/deploy_mujoco_rl.py \
  --config src/controller/rl/config/primuus.yaml \
  --xml-path src/controller/rl/resources/site/scene_primuus_stairs.xml
```

`--xml-path`只替换场景，策略路径、关节顺序、PD和观测仍由Primuus配置决定。
其他场景将上述命令中的`scene_primuus_stairs.xml`替换为`scene_primuus_narrow_bridge.xml`、
`scene_primuus_ramp.xml`、`scene_primuus_high_wall.xml`、`scene_primuus_limit_frame.xml`、
`scene_primuus_stepping_stones.xml`、`scene_primuus_tire_array.xml`或`scene_primuus_brick_wood_pit.xml`即可。
已有平地策略不保证具备越障能力。默认`primuus.yaml`继续指向平地，审核场景通过命令显式选择。

## 后续训练接入

该XML用于MuJoCo场景加载，Isaac Gym训练需依据相同尺寸另外构建碰撞地形。
按规则第4.3节，台阶通过要求每一级顶面至少与足底接触一次；后续成功判定需记录各级接触。
单木桥需从短边进入并从另一短边离开；侧面摔下或半数及以上足接触地面需重新越障。
高墙需从上方跃过或攀爬通过，绕行不算完成。独立斜坡仅用于练习沟壑组合中的上坡或下坡，
不能据此认定完成整个沟壑组合障碍。
梅花桩需从一侧平台进入、从另一平台离开，并至少触及每个桩顶一次；侧面摔下或半数及以上足触地需重新越障。
轮胎阵需从短边踏入、从另一短边离开；半数及以上足接触阵列外矩形地面需重新越障。
轮胎中心孔和胎间空隙位于阵列矩形内，不能把所有地面接触不加区分地判成该项失败。
砖木坑需从一条短边进入、另一条短边离开；半数及以上足接触坑外地面需重新越障，判定区域应使用L形轮廓而非外接矩形。
