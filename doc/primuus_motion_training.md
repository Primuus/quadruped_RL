# Primuus 训练配置与基础奖励

Primuus 使用独立模型、默认角、关节损耗、PD和指令采样器。
当前启用奖励的名称、权重及计算公式对齐2026-10-20的`e961f13`版本，共17项。
所有运动状态恢复统一0.28±0.03m高度目标；指令采样和速度范围保持当前设置。
此前保留的额外整形项权重仍为0。
此版本应使用独立run从头训练，不加载此前1000轮策略或优化器。
代码更新不自动启动正式训练，也不替换部署策略。

## 当前有效奖励

| 项目 | 权重 | 机制 |
|---|---:|---|
| tracking_lin_vel | 1.0 | exp(-XY速度误差平方和 / 0.25) |
| tracking_ang_vel | 0.5 | exp(-偏航角速度误差平方 / 0.25) |
| lin_vel_z | -2.0 | 机身竖直速度平方 |
| ang_vel_xy | -0.05 | 横滚/俯仰角速度平方和 |
| orientation | -0.2 | 重力投影XY分量平方和 |
| dof_acc | -2.5e-7 | 关节加速度平方和 |
| base_height | -0.4 | 超出统一0.28±0.03m高度容差后的归一化平方误差 |
| foot_clearance | -0.01 | 摆动足机身系高度误差平方×水平相对速度，排除支撑足 |
| foot_slip | -0.10 | 触地足对地水平速度平方和 |
| turn_step | 0.1 | 合格转向换步，按每足时间预算及XY/yaw跟踪计分 |
| action_rate | -0.01 | 动作一阶差分平方和 |
| smoothness | -0.01 | 动作二阶差分平方和 |
| torques | -0.0002 | 电机力矩平方和 |
| collision | -1.0 | 持续非足端接触数量 |
| stand_still | -0.1 | 零参考指令时，关节相对本机默认角的绝对偏差之和 |
| stand_contacts | -0.4 | 零参考指令时，缺少支撑的足端比例 |
| dof_pos_limits | -10.0 | 实际关节角超软限位的幅度之和 |

`tracking_sigma=0.25`是误差平方的指数分母，不是标准差。
前进指令1m/s时，实际速度为0、0.5、1m/s的线速度奖励分别约为0.0183、0.3679、1。
取消原来的绝对/相对窄容差公式；转向和转向换步也使用同一宽跟踪公式。

抬脚使用通用 `LeggedRobot._reward_foot_clearance`：足端目标机身系高度-0.20m，
高度误差尺度0.05m。计算相对足速时扣除机身平移与 `omega × r` 再转到机身坐标系；
仅未触地且有水平相对运动的足端产生代价。不再用摆动峰值、持续对地高度区间或方向整形作为抬脚奖励。
这仍是高度引导惩罚，不强制固定四足相位，也不额外奖励长时间腾空。

零参考指令掩码与通用基线一致：XY模长和yaw绝对值均不超过0.1。
站姿偏差直接使用本机默认角，不再使用带容差的归一化强回正公式；
支撑足使用5N阈值并保留一帧接触滤波。缺足奖励直接按四足缺失比例计分，
不使用原0.4秒换脚宽限；`Standing/support_grace_fraction`在当前基线中为0。

今天增加的整形奖励仅保留`foot_placement`和`stand_height`，两项权重均为0；
摆脚方向、不可达目标角和站姿足端区域的额外奖励及其配置已删除。
此前已有的`braking`、`stand_joint_motion`权重仍为0。
`feet_air_time`仍为0。直行对称奖励、左右偏置日志和对应课程门槛已删除；
动作镜像一致性损失、热身参数和估计器镜像数据增强也已删除。
HIM估计器仍使用原始观测学习速度和隐变量，保留正常估计与表征损失。
两种镜像机制均由2026-10-20的`f6f5527`新增，不属于此前原有的HIM训练流程。
`only_positive_rewards=False`、终止奖励0，均与参考基础配置一致；本次不额外改变终止激励。

## Primuus 专有配置

以下设置保留，不按参考机器人覆盖：

- 默认角：四腿hip=0、thigh=-0.75、calf=-1.5rad。
- PD=60/1.5，action_scale=0.25；物理2ms、策略20ms。
- actor观测270、critic观测238、动作12；HIM-PPO优化参数保持原值。
- 所有运动状态的高度目标统一0.28m，容差±0.03m，与旧17项奖励版本一致。
- 前进最终0.12–2m/s，后退/侧移/斜移/边走边转平移上限1m/s，偏航最终上限2rad/s。
- 80%环境常规采样：站立20%、前进35%、后退10%、侧移10%、斜移5%、原地转向10%、边走边转10%。
- 其余10%练直行源段的动作切换，10%练六类运动后的停车；常规运动保持3–5秒，零目标保持6–8秒。
- 参考指令过渡：平移加速3、减速4、停车减速6m/s²，偏航加速3、停车制动4rad/s²。

这些是采样器设定，不是实际训练时间占比；复位、保持时长和序列会改变实际占比。

## 课程与诊断

前向课程仍为1→1.5→2m/s，原地/移动转向初始1、最终2rad/s。
本次仅恢复奖励，不放宽已有课程验收：高速跟踪、失败率、各足接触、落脚区域、
抬脚测量、停车回正和低速26方向覆盖等门槛仍参与晋级判断；不再验收左右镜像位置偏置。
最大配置范围不代表当前检查点已经学会该范围。

`gait.py`和`standing.py`仍测量每足区域、对地抬脚、目标可达性及正常姿态，
用于日志、课程和成功判据。旧 `Gait/clearance_violation` 是原对地高度区间的诊断，
与本次机身系目标高度奖励定义不同；实际抬脚奖励应看 `Episode/rew_foot_clearance`。
关闭奖励不代表对应诊断或课程门槛也关闭，晋级停滞时须同时检查门槛和样本数。
课程状态版本为v4；旧状态保留速度上限，重新累计变更后的质量指标窗口。

严格正常站姿仍要求：关节距本机默认角hip/thigh/calf分别不超过0.10/0.20/0.20rad，
四足XY距各自默认中心不超过0.03/0.025m，高度0.28±0.03m、倾斜不超过0.15rad。
进入严格稳站还需四足支撑、参考归零、机身水平/偏航速度低于0.05及关节速度RMS低于0.25。
停车成功完整观察5秒。姿态判据保留用于验收，不作为额外强回正奖励。

训练分析必须同时看回合长度、按运动状态的速度误差、正常站姿/停车失败率和确定性部署结果。
`Train/mean_reward`是每回合累计值；`Episode/rew_*`按最大回合时长20秒归一，
回合缩短会改变两者，不能只凭回报上升或惩罚下降认定效果改善。

测试脚本应在工程外运行，验证结束清理本地和服务器临时脚本、模型、日志与缓存；
正式训练日志、检查点和运行记录保留。工程更新通过验证后提交当前分支并推送。
