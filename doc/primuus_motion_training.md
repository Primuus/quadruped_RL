# Primuus 步态、制动与转向课程

本版本保持 actor 输入270、动作12、critic输入238，以及机械模型、PD和关节损耗定义。
本轮采用独立run从头训练，不加载旧策略/优化器，不使用`--resume`。前进上限从1 m/s开始，
通过速度、步态和停车验收后逐级增加至2 m/s。技术上的旧检查点可读兼容不代表推荐续训。

新训练使用独立名称，例如：

```bash
python quadruped_rl/scripts/train_primuus.py --headless --run_name foot_placement_fresh
```

## 指令和阶段

- `requested_commands`：采样器提出的目标。
- `commands`：实际进入观测、执行和跟踪奖励的参考指令。
- `motion_phase`：0行走、1制动、2收稳、3稳站。

运动目标独立保持3–5秒，零目标保持6–8秒。80%的环境按七类概率采样；10%运行直行源段
与停车/后退/移动转向/斜移/原地转向目标段；10%在六类运动中均匀选取一个源段，再停车回正。
前进采样区间为0.12–0.5、0.5–1、1–2 m/s，完全开放后占30%/40%/30%。
整体实际时间占比会随不同保持时间、序列和复位改变，
不能继续将原七类概率解释为全体环境的精确时间占比。

非前进平移类中，0.12–0.4 m/s和更高速度子区间各占50%；斜移的一半角度取45°，
移动转向的一半角度取键盘的八个精确方向，其余保留连续方位角。
这使 S+Q 等键盘组合拥有直接训练覆盖。

`reference.py`与部署 `core/command_reference.py`采用相同规则和秒制参数：

| 参数 | 值 |
|---|---:|
| acceleration | 3 m/s² |
| deceleration | 4 m/s² |
| braking_deceleration | 6 m/s² |
| yaw_acceleration | 3 rad/s² |
| yaw_braking | 4 rad/s² |
| transition_speed | 1 m/s |

高速直行先减至1 m/s范围再引入侧移/转向。退出转向时先收掉偏航参考，再恢复高速直行。
停车目标立即清零，参考通过独立减速度收至零。参考更新在每个20ms策略周期进行，不能放到物理子步中重复执行。

## 奖励与对称训练

线速度误差尺度为 `0.08 + 0.10 * |v_cmd|`，偏航误差尺度为
`0.08 + 0.10 * |yaw_cmd|`，分别平方后作为指数跟踪分母。低速完全不执行的收益明显降低，
高速仍保留相对误差余量。原前进课程的高速度段分数仍使用原 `tracking_sigma`，不混同两类指标。

零目标下的制动奖励采用参考跟踪误差的平滑绝对值，避免高速误差都落入接近零的指数分数。
参考已经归零且实际水平/偏航速度降低后，默认关节角、正常落脚位置、站立高度和四脚支撑约束平滑启用。
姿态尚未回正时，关节静止惩罚按姿态恢复程度减弱，避免把歪着不动当作低成本解。
不要求尚在高速制动的机器人立即摆成静态站姿。

稳态直行中，以0.8秒时间常数统计左右足端平均位置的镜像偏差，保留为诊断指标。
`straight_symmetry`奖励权重暂设为0，不计入训练回报；动作镜像一致性训练继续保留。

HIM-PPO增加确定性动作均值的左右镜像一致性损失，系数0.05、200轮线性热身；
不改变原PPO采样动作和旧策略概率。HIM估计器独立追加镜像历史及对应速度/特权标签。
Primuus髋轴在模型中已经镜像，关节与动作交换 FL/FR、RL/RR，无需套用其他机器人的符号。
六帧观测均变换命令vy/yaw、轴向角速度x/z、重力y及关节/上次动作顺序；
critic额外变换真实速度y、外力y及17×11高度网格y方向。

## 晋级门槛

前进只统计当前上限80%以上的直行段：切换后先留1秒，再至少统计1秒，每20秒检查，至少200个完整段。
原跟踪分数≥0.8、失败率≤5%之外，还要求下表全部通过，且下述停车/低速方向质量门槛通过。
没有足端测量、测量非有限或样本不足时不晋级；早期摔倒仍计入失败。

| 高速段质量指标 | 晋级阈值 |
|---|---:|
| 长期左右足端位置偏置 | ≤0.035 m，仅作验收门槛，奖励仍为0 |
| 足端活动区域越界比例 | ≤5% |
| 触地足水平滑移均速 | ≤0.12 m/s |
| 机身平均倾斜角 | ≤0.25 rad |
| 不可达目标角分量比例 | ≤1% |
| 抬脚区间违规比例 | ≤5% |
| 运动状态高度目标平均误差 | ≤0.04 m |
| 每只足的触地占比 | 各自≥15%，允许交替支撑与腾空 |

步态指标先对每个完整段求均值，再对段求均值；足端越界比例以四足样本为分母，目标角比例以12关节分量为分母。
过渡起始速度从1 m/s按0.5递增，最多到当前前进上限；同时要求步态验收通过。
过渡和停车各至少200个已完成事件，失败比例不超过2%；前进/后退/侧移/斜移/原地转向/移动转向后的停车各至少50个事件且各自失败率≤2%；低速26个方向类别分别达到200个样本，
XY均误差不超过0.10 m/s，yaw均误差不超过0.15 rad/s，才允许提高过渡难度。

修复阶段至少120仿真秒、过渡起始速度达到2 m/s且质量门槛通过后，才允许提高转向上限。
原地与移动转向分别统计，左右方向分别至少200个高偏航段、均绝对误差不超过0.20 rad/s、
失败不超过2%，每次增加0.25 rad/s，最终目标2 rad/s。
新课程和门槛是训练控制机制，不表示旧策略或短测试已经学会这些能力。

课程保存为v3，保存新足端评估窗口及上次结果，兼容读取v1/v2的速度上限。
旧窗口未采集足端质量时一律清空；重建仿真时清除执行中的运动段、足端中心及触地基准。

## 日志与验收

- `Loss/symmetry`：未乘热身系数的镜像一致性损失。
- `Symmetry/position_bias`：稳态直行的周期平均足端位置偏差，单位m。
- `Tracking/low_xy_error`、`low_yaw_error`：参考已接近目标时的低速执行误差。
- `Tracking/directional_low_*_error/direction_N`：各部署方向的低速误差。
- `Phase/*_fraction`：各阶段的实际时间占比。
- `Stopping/failure_rate`、`Transition/failure_rate`：已完成/失败事件的比例。
- `Stopping/body_time`、`distance`、`quiet_time`：仅成功停车事件的指标。
- `Transition/acquisition_time`：经过平滑速度评估的目标获取时间。
- `Transition/interrupted`、`censored`：每训练迭代的中断/超时截断事件数，需结合样本量解释。
- `Curriculum/turn_limit`、`moving_turn_limit`、`transition_limit`、`repair_elapsed`、`quality_ready`。
- `Gait/foot_region_violation`、`center_error`、`foot_slip_speed`、`tilt`、`target_violation`、`clearance_violation`、`height_error`、`swing_clearance`：全体环境的逐步诊断。
- `Curriculum/gait_*`：完整高速指令段的质量均值、各足触地比例、已评估段数和是否通过。`gait_ready`和`quality_ready`应同时观察。

方向类别0/1为前/后，2/3为左/右，4–7为左前/右前/左后/右后，8/9为原地左/右转。
10–25为八个方位（前、左前、左、左后、后、右后、右、右前）各自叠加左/右转。

停车事件完整观察切换后5秒，不能在第2秒短暂站好时提前计成功；5秒末未恢复正常站姿并稳站记失败。
其他运动切换仍至少观察2秒、5秒未完成记失败。新目标提前打断记中断/失败，回合自然超时单独截断。
机身停止要求水平和偏航速度低于0.1并持续1秒；严格稳站要求两者低于0.05、
关节速度RMS低于0.25 rad/s、四足支撑、参考指令归零且持续0.5秒；还必须满足下文正常站姿标准。
机身停止的基础直立判断仍要求高度>0.18m且倾斜<30°。
每个事件记录达到连续稳定区间的起始时刻。

课程晋级使用训练随机动作指标；部署验收使用确定性策略。两者不可直接混为同一误差。
继续用四档104个基础组合、42项升降档、48项方向切换和多步态相位停车作对照，
再扩大摩擦和起始状态覆盖。全部测试脚本、smoke权重、测试日志与缓存应在验证后立即清理。

代码更新不自动启动正式训练、不修改本地部署权重。部署当前四档yaw已为0.5/1/1.5/2 rad/s，
训练初始课程仍为±1 rad/s；部署最终包络不代表当前策略已经学会该上限。

## 足端区域、抬脚与目标可达性（2026-10-21）

`gait.py`从正式URDF和默认角做正运动学，得到FL/FR足端中心约为`[0.2411, ±0.1495]` m，
RL/RR约为`[-0.1853, ±0.1495]` m。使用每条腿自己的位置和机械范围，不设置四腿相位表。

`foot_placement=-0.4`包含三种归一化平方越界量，四腿取均值：单足XY活动区域、跨入机身中线附近、
0.6秒时间平均足端中心偏移。所有项都有容差，位于区域内不扣分；归一化尺度为0.04 m。
直行支撑足前后半宽为`0.10 + 0.05*|v_xy|` m，摆动足另加0.04 m；横向半宽0.04 m，
侧移/转向按各自参考速度归一化后最多另加0.025 m。足端距中线至少0.075 m。
平均中心前后容差为`0.04 + 0.005*|v_xy|` m，横向容差0.025 m，混合动作同样增加余量。
这些是单足几何范围约束，`straight_symmetry`奖励继续为0，镜像辅助训练沿用现有配置。

`foot_clearance=-0.05`改为相对每足真实触地时的高度基准。摆动前0.06秒允许逐渐抬脚，
之后要求本次摆动峰值达到0.025 m；达到后允许自然下落，不在着地前再次逼迫抬高。
离地上限为`0.07 + 0.008*|v_xy|` m，限制不必要的大幅收腿。两端越界按0.04 m归一化。
基准仅由原始触地力更新，延长一帧的接触滤波不会把已经抬起的足端当成新地面。
课程的滑移速度也只使用原始触地足，避免将刚离地足的运动速度误计为滑移。
本实现针对平地，未引入楼梯或地形高度测量。

`joint_target_limits=-0.3`约束`default_angle + action_scale*action`超出URDF硬限位的部分，
按0.25 rad归一化后平方、12关节平均。它与实际关节角软限位奖励同时保留；不增加硬裁剪，
避免训练与部署的PD目标处理不同。PD、力矩上限、动作缩放和机械限位均沿用当前契约。

高度按实际执行的参考指令判断：站立0.30、前进0.28、后退0.27、侧移/斜移/原地或移动转向0.25 m，
容差均为±0.03 m。参考尚在高速减速时保留前进高度目标，不按尚未执行的新目标提前压低机身。
以上权重和阈值是本轮训练的初始设置，需要新策略的确定性评估验证，不能据代码检查宣称步态已改善。

## 停车后的正常站姿恢复

`standing.py`对每条腿分别检查关节和落脚位置，yaw不要求恢复某个世界朝向。
正常站姿要求hip/thigh/calf距默认角分别不超过0.10/0.20/0.20 rad，四足XY距本腿默认中心
分别不超过0.03/0.025 m，高度0.30±0.02 m、倾斜≤0.15 rad。再满足低速度、低关节速度、
四足接触且参考归零，才允许进入`motion_phase=3`或记为停车成功。

站立目标0.30 m接近默认角对应的足端高度，保留带载关节误差；侧移/转向0.25 m结束后应恢复正常高度。
`stand_still=-0.8`改为关节越出容差后的非饱和平滑惩罚，尺度0.15 rad、12关节平均；
新增`stand_foot_placement=-0.4`和`stand_height=-0.2`，分别按0.04 m和0.05 m归一化越界量。
`stand_joint_motion`乘以姿态恢复程度，允许尚未回正的腿继续调整；未给部署添加强制拉回默认角的控制器。

六类运动后的停车分别累计样本和失败率，任一来源未通过均不允许课程晋级。
日志新增`Standing/pose_error`（关节误差RMS，rad）、`foot_error`（最大XY偏差，m）、
`height_error`和`normal_pose_fraction`，以及`Stopping/from_<mode>_failure_rate`。
零目标保持6–8秒，因此实际站立时间占比会高于相同采样概率、3–5秒保持时间的旧版本。
训练与部署前进指令上限现为2 m/s；部署四档为0.5/1/1.5/2 m/s，后退、侧移和yaw档位保持原值。
本轮仍采用独立run从头训练，旧策略不会自动获得这些回正行为。

实现验证覆盖2 m/s采样和旧课程上限收窄、六类动作→站立的序列、关节/足端/高度/倾斜的独立判定、
5秒观察期、迟发塌姿、参考未归零、超时截断、逐来源课程门槛，以及部署四档和参考一致性。
服务器32环境带观测噪声运行256步，23项非零奖励及观测均有限；另以旧策略执行32组六类动作后停车，
末段平均水平速度约0.003 m/s，但正常姿态比例为0，新验收将其计为失败，未产生优化器或正式训练日志。
独立MuJoCo默认关节目标承重检查达到高度0.293 m、足端最大XY偏差0.0226 m、倾斜约0.019 rad，
通过新正常站姿标准；这验证标准可达，不代表旧策略已学会回正。正式新训练未启动。

此前4 m/s版本的足端实现验证记录：覆盖单足越界/跨中线、速度和运动状态余量、触地基准、拖脚与过高抬脚、自然落脚、
目标角硬限位、各项质量门槛、缺失测量禁止晋级、早期失败及v3/v2课程状态读取。
URDF正运动学与本地MuJoCo默认姿态足端位置的最大差约1.4e-16 m。
服务器Isaac Gym以32环境运行256步随机动作，观测/奖励有限，未创建优化器。
同一3250轮策略另做1/4 m/s推理检查，统计后4秒：足端区域越界约44.4%/43.9%、
触地足滑移均速0.105/0.275 m/s、抬脚区间违规约5.7%/29.6%，4 m/s目标角越界约2.4%。
这些检查说明新指标能够检测已知异常，不代表已训练出改善后的策略；正式训练尚未启动。
